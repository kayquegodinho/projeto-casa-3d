# Projeto da casa — visualizador 3D

Estudo interativo em escala para revisão do projeto com o engenheiro.

## Abrir
https://kayquegodinho.github.io/projeto-casa-3d/

Arraste para girar; use a roda do mouse para aproximar e o botão direito para deslocar. Selecione um ambiente no painel lateral. As opções de paredes rebaixadas e coberturas permitem explorar os interiores. A ferramenta de medição permite conferir distâncias no modelo.

Uma unidade do modelo corresponde a um metro. O visualizador representa um estudo de projeto, não um projeto executivo validado.

## Compartilhar observações
Envie imagens com anotações e medidas. Alterações no modo de edição ficam apenas no navegador de quem as fez; use a opção de baixar a organização para compartilhar o arquivo JSON. Elas não alteram a versão publicada.
